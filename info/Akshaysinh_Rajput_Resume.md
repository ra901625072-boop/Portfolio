## Projects

### Multi-Agent Automation Agent
A voice- and text-mode automation agent capable of completing complex goals through multiple specialized sub-agents, including a coding agent, a research agent, and a planning agent.
**Tech Stack:** Python, HTML, CSS, JavaScript, and various open-source and free AI APIs/models.

### Pali CBDC Portal
A web application built to track beneficiary data for the Central Bank Digital Currency (CBDC) rollout in Pali. Users can check whether their name appears on the beneficiary list. Talati (village-level administrators) can log in as admins to view completion analytics, beneficiary details, and download reports.
**Tech Stack:** Python, HTML, CSS, JavaScript, SQL

### e-Grossary Mart
An e-commerce style web application built for a client to manage supply, stock, and suppliers, with a dashboard to track revenue and other business metrics. On the customer-facing side, regular users can browse and purchase items, similar to a standard e-commerce site.
**Tech Stack:** Python, HTML, CSS, JavaScript, SQL

### FamDoc (Family Document Manager)
A Google Drive–style application where users create an account and generate a unique family code. Other family members join using this code, and any document uploaded by a member becomes visible to and downloadable by the whole family — eliminating the need to search for or request documents individually.
**Tech Stack:** Python, HTML, CSS, JavaScript, Google Drive API, MEGA, SQL

### Resume Maker
A web application built for students or anyone unfamiliar with design tools. Users log in, enter their personal details, and choose from several professional resume templates, then download the finished resume.
**Tech Stack:** Python, HTML, CSS, JavaScript, SQL
